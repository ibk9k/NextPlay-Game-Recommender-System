# Product

## Register

product

## Users

PC players choosing their next Steam game, and the project team demonstrating the
three recommendation techniques in the proposal. A player rates familiar games,
compares recommendations, or describes the game they want to play.

## Product Purpose

Help players find games through tag similarity, similar-player preferences, and
neural description search. Success means a usable ranked top-10 list, understandable
recommendation reasons, saved 1-5 ratings, and accurate disclosure of demo data.

## Brand Personality

Familiar, compact, clear. The user chose a dark, Steam-like library and confirmed
Python/FastAPI, SQLite, a lightweight browser interface, and a pretrained encoder.
Nextplay is a working interface name; the academic project remains Game Recommender System.

## Anti-references

The user explicitly asked to avoid decorative dashboards. Avoid marketing heroes,
gratuitous statistics, ornament that competes with game covers, and unsupported
claims about recommendation accuracy.

## Design Principles

- Start with games and the player's task; make browsing and rating immediately available.
- Keep the three proposal techniques independently accessible and name the method used.
- Explain each recommendation in ordinary language.
- Identify synthetic peers, fallbacks, and lexical search honestly.
- Preserve context when rating, filtering, navigating, or recovering from an error.

## Accessibility & Inclusion

The chosen direction includes keyboard access, readable contrast, and reduced motion.
Use semantic controls, visible focus, labeled ratings, meaningful loading and error
states, and responsive navigation. Target WCAG AA text contrast.
